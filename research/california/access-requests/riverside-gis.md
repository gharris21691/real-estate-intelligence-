# Riverside Parcel Basic request

## Submission route

- Submit through Riverside County's [Public Records Act Portal](https://riversidecountyca.nextrequest.com/requests/new).
- Address the request to Riverside County Information Technology (RCIT), GIS/Open Data. If that department is unavailable, ask that the request be routed to the team responsible for the `OpenData/Assessor` ArcGIS service.
- This request asks for existing policy or documentation and confirmation of permitted use; it does not ask the county to create a new record.

## Request

**Subject:** Automated-use terms for Riverside Parcel Basic ArcGIS layer

Hello,

I’m evaluating Riverside County’s public `PARCELS` layer in the `OpenData/Assessor` ArcGIS service for an internal real-estate research project. The layer exposes only `OBJECTID`, `APN`, `FLAG`, and parcel geometry, reports a 2,000-record limit, and says it is updated Monday through Friday.

May we query the layer automatically once a week, page through the results using the published ArcGIS REST interface, retain dated snapshots, and create internal derived tables for commercial research?

Our first phase would use only those basic parcel fields. It would not query the `PARCELS_CREST` layer, owner names, or mailing-address data, and we would not republish the county's source records.

Please send or identify any existing policy covering automated access, acceptable request frequency or concurrency, storage and retention, attribution, redistribution, and service-change notifications. If another team owns this service, please route the request to that team.

Thank you,

Gabriel Harris
