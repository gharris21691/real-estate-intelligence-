## Verified access profile

| Field | Finding |
| --- | --- |
| Record scope | The online General Index covers documents recorded in Sacramento County since 1849. Common examples include deeds, deeds of trust, reconveyances, assignments, and liens. |
| Geographic scope | Sacramento County recorded instruments. |
| Access method | Public web index for discovery. Documents may be viewed at Recorder offices; copies may be ordered by mail, fax, telephone, or in person. |
| Authentication | No account requirement is published for the index landing page. |
| Search inputs | The County describes searches by party name and recording year. |
| Identifiers | The copy workflow uses Recorder book and page references. Document title, party, and recording year are discovery attributes. |
| Images | Actual recorded documents are not viewable in the online index. |
| Historical depth | 1849 onward for the online index; the copies page describes recorded documents since 1850. This wording difference should be confirmed if boundary-year records matter. |
| Update cadence | The legal disclaimer says the index is generally updated within two business days of recording. |
| Cost | Index searching is presented as public access. Non-certified copies are $8 for the first page plus $1 per additional page; certified copies are $9 for the first page plus $1 per additional page. |
| Accuracy | Index accuracy depends on the information in documents accepted for recording. |
| Formats | Browser index and ordered/viewed document copies. No official bulk file or API was identified. |

## Related but distinct transfer source

The Assessor fee schedule lists a no-charge, electronic two-year Change in Ownership transfer file derived from the Recorder’s Index and updated monthly. That file may be a better approved path for recent parcel-transfer events, but it is not the Recorder’s complete General Index and must be evaluated under its own layout, coverage, and terms.

Do not combine the two sources conceptually:

- Recorder General Index: document-centered, party-indexed official-record metadata covering a broad historical range.
- Assessor transfer file: parcel-oriented, recent two-year transfer extract with monthly updates.

## Risks and limitations

- The index is a discovery tool, not a document-image feed.
- Party-name matching cannot establish parcel or person identity by itself.
- No published API, bulk product, rate limit, or permission for automated querying was found.
- Copy costs support case-specific evidence gathering, not broad document collection.
